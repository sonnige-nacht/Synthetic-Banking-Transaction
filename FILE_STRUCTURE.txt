FOLDER AND FILE PURPOSES

datasets/ contains source data and information on its origin and publication.
python/ contains the exploration notebook, SQL Server loader, and fraud model.
sql/ contains schema creation, inspection, cleaning, and view scripts.
requirements.txt lists Python dependencies. .gitignore excludes local environments, secrets, notebook checkpoints, and the large CSV.

Downloaded data files and archives are excluded from Git due to their size. Download the dataset from the source in DATASET.txt. The original virtual environment is omitted. The scripts needed to populate staging and warehouse tables are not present; see README.md.
